# Runtime dependencies for every platform. Lower bounds are versions known to work;
# the API clients are capped at their next major release so a self-update on the
# unit can't pull in a breaking change.
#
#   Pi (Raspberry Pi OS Trixie, Python 3.13): pi_setup.sh installs this file, plus
#     openwakeword --no-deps with onnxruntime (tflite-runtime has no 3.13 wheels),
#     the Pi 5 GPIO shim and the optional VL53L1X driver, and downloads the models.
#   Mac: `brew install portaudio` first (PyAudio builds against it).
#   Windows: PyAudio ships prebuilt wheels; nothing extra.
#
# Not listed, installed by pi_setup.sh or apt because pip can't build them everywhere
# (the modules no-op when they are missing): VL53L1X (proximity sensor), picamera2
# (camera), rpi-ws281x (WS2812 eye LEDs — see CANDLE_WIRING.md), RPi.GPIO/rpi-lgpio.
