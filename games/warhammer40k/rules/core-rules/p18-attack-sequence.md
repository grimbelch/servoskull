# ATTACK SEQUENCE

######

###### **Whenever models make attacks, you will follow the sequence detailed in this section to find out if they inflict damage.**

<!-- Start of picture text -->
Each time the active player is instructed to resolve the<br>attack sequence, they follow the steps below. In each step,<br>if there is more than one dice to roll, make all of those<br>rolls simultaneously.<br>1 HIT ROLLS<br>2 WOUND ROLLS<br>3 SAVE ROLLS<br>4 INFLICT DAMAGE<br><!-- End of picture text -->

**WHEN DOES THIS SEQUENCE END?** _If an attack fails or inflicts damage, this sequence ends for that attack. When all attacks have either failed or inflicted damage, this sequence ends and those attacks have been resolved._
