###### **RAPID DISEMBARK**

_When a unit uses the_ **_rapid disembark_** _mode after its_ **`TRANSPORT`** _makes an_ **_ingress move_** _, the models must follow the same rules and restrictions as that_ **`TRANSPORT`** _did. For example, if that_ **`TRANSPORT`** _had to be set up more than 8" from all enemy units and not within your opponent's deployment zone, the same applies to the disembarking unit._

###### **`EMERGENCY DISEMBARK MOVE`** 18.05

<!-- Start of picture text -->
SET-UP DISTANCE: 6"<br>ELIGIBLE IF: Your unit is embarked within a TRANSPORT model<br>that was just destroyed .<br>EFFECT: Your unit is set up as described in Set Up (03.02).<br>BEFORE MOVING: Make a hazard roll for each model in your<br>unit (06.03).<br>WHILE MOVING: Set up each model in your unit wholly within<br>the set-up distance of that TRANSPORT , and as close as possible<br>to that TRANSPORT . Each model that cannot be set up in this<br>way is destroyed .<br>AFTER MOVING: Your unit is battle-shocked and, until the end<br>of the turn, it is not eligible to declare a charge .<br><!-- End of picture text -->
