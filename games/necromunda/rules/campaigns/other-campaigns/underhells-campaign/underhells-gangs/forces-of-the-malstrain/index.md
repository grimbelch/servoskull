# Forces of the Malstrain

[RAW ✔️](/docs/publication-index/rules-index) *Necromunda: Hive Secundus Rulebook, p148*

## Building Malstrain Forces

The Malstrain builds their forces using the following unit entries. In order to simplify
matters, instead of using credit values for building their forces, the Malstrain player
uses Malstrain Points with each fighter costing a certain amount based upon their
type as shown below:

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |

| Malstrain Fighter Malstrain Points |
| --- |
| Brood Scum with up to 40 credits of equipment 1 |
| Malstrain Tyramite 1 |
| Malstrain Genestealer 3 |

These fighters can all be represented by the Fighter cards included in the
Necromunda: Hive Secundus boxed game. In order to build the Malstrain forces,
simply spend the available MP on Fighter cards following the guidelines below:

- The Malstrain forces must include at least as many Brood Scum as fighters the
  Malstrain deploys on the battlefield during the Deployment step of the
  pre-battle sequence.
- The Malstrain forces may include a number of Malstrain Genestealers in their
  forces based on the level the battle is taking place on (see the table below).
  Each Malstrain Tyramite must be assigned to a Brood Scum for the duration of
  the battle.

Depending on the level in the Underhells the Secundan Incursion gang has reached,
there will be a maximum number of Malstrain Genestealers that can be included in
the Malstrain forces as indicated below:

|  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

| Level Number of Malstrain Genestealers |
| --- |
| Level One and First Descent 1 |
| Level Two and Second Descent 3 |
| Level Three 4 |
| Broodthrone Unlimited |
