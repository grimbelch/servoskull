# Setting Up The Campaign

[RAW ✔️](/docs/publication-index/rules-index) *Necromunda: Hive Secundus Rulebook, p112*

Setting up an Underhells Campaign is a task that falls to the Arbitrator. To set up
the campaign, the Arbitrator must make sure that the Secundan Incursion gang
player has created their gang. This is best done in a single evening or session, where
both players in the campaign meet and go through all the steps of setting up the
campaign together and generally get excited about the fun ahead.

## Set Start And End Dates

The Underhells Campaign is divided into six campaign cycles, broken up by a cycle
of downtime each time the hunters descend to a new level of the Underhells. For
ease we have set each cycle as a week, as this is usually how often gaming groups
or groups of friends get together to play. However, if the players choose, a cycle can
represent a longer or shorter period of real time.

The first step in setting up the campaign is for the Arbitrator to determine the start
date and the end date. They then share this information with the other player.

## Issuing and Accepting Challenges

During an Underhells Campaign, battles are fought on a challenge basis:

- During each cycle the player who won the last battle issues a challenge to the
  other player. This means they get to choose which route the Secundan Incursion
  gang are taking as they explore the Underhells and so which Territory will be the
  stake for the battle.
- During the first cycle, the Secundan Incursion gang player gets to issue the
  challenge as they enter the depths of Hive Secundus.
- If a fighter from the Secundan Incursion gang has been captured by the Malstrain,
  then any captives will be the stake for the battle in addition to the usual Territory.
  The scenario is automatically [Prisoner of the Cult](/docs/campaigns/other-campaigns/underhells-campaign/battlefield-setup-scenarios/scenario-list/prisoner-of-the-cult) - there is no
  need to roll on the Scenario Selection table.
  - If the fighter is not successfully rescued then they are automatically slain by the
    Malstrain. Delete the fighter from the Secundan Incursion gang roster.
- Only one challenge is issued each cycle.

If the Secundan Incursion gang player wins the scenario, they take control of
the Territory.

## Scenario Selection Table

When a challenge is issued, roll 2D6 on the table below to determine which scenario
is used.

|  |  |  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

| 2D6 | Result |
| --- | --- |
| 2-3 | The Malstrain player chooses which scenario to play from those found on [pages 130-137](/docs/campaigns/other-campaigns/underhells-campaign/battlefield-setup-scenarios/scenario-list/). |
| 4-5 | Play the Into the Underhells or the Brood Ambush scenario. |
| 6-7 | Play the Data Crystal Harvest or the Descent into the Dark scenario. |
| 8-9 | Play Champion of the Malstrain or the Purge the Brood scenario. |
| 10-12 | The Secundan Incursion gang player chooses which scenario to play from those found on [pages 130-137](/docs/campaigns/other-campaigns/underhells-campaign/battlefield-setup-scenarios/scenario-list/). |

Where there is a choice of two scenarios to play, the player who is challenged
decides which scenario to play.
