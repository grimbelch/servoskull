# Rules Index

This is an exhaustive list of all current Necromunda rules publications.
Publications with obsolete content are not listed here.

## Sources Classification

The classification of sources is now based on the table below. If a badge is present at the top of a page, it characterises the entire page's content. If there are no badges at the top of the page, look for badges within the content itself. A badge will likely be displayed where the source is usually shown.

| Badge  Alt Text  Description |
| --- |
| [RAW ✔️](/docs/publication-index/rules-index) `RAW-Verified` Contains only verbatim rules (RAW). Presentation might differ from the printed version. |
| [RAI 📝](/docs/publication-index/rules-index) `RAI-ToBeTranscribed` Content is a summary of the verbatim rules. Verbatim transcription is planned. |
| [RAI ⚡](/docs/publication-index/rules-index) `RAI` Content interprets and summarises verbatim rules. No plans to alter this. |
| [OBS. ☠️](/docs/publication-index/rules-index) `OBS.` Content is obsolete and has been superseded by an ulterior publication. |
