# New Player? Here is Where to Start

NecroRAW

If you are a new player, you might feel overwhelmed by the amount of content available for Necromunda.

This infographic will guide you in choosing which book or box set to buy.
NecroRAW is not meant to replace the official books, which provide valuable lore
and artwork to help you grasp each gang's background and the game's overall atmosphere.
